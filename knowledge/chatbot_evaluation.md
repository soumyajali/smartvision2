### 1. What is Smart Vision?

> Smart Vision is a computer-vision application with two front ends that share one Python backend:
> - A **website** (Streamlit, `streamlit run app.py`) and
> - An **Android app** (Flutter).
> 
> Main features: real-time object detection (YOLOv8), Fast Video Review, OCR with translation and summarization, face registration and recognition, a Drowsiness Monitor, Research Evaluation, an AutoML & Dataset Pipeline view, detection History, Settings, a Vision Chatbot and a Voice Assistant.
> The phone runs object detection, OCR, translation and drowsiness checks on the device. Face identity, reference-video search, dataset/storage analytics and the server chatbot need the Smart Vision backend (`uvicorn ai_server:app --host 0.0.0.0 --port 8000`).

### 11. How does Fast Video Review find matching frames?

> The reference search reproduces the website's algorithm:
> - **Reference preparation:** if the reference shows a face, the target is that person and frames are compared by face (face_recognition encodings when that library is installed, otherwise YuNet/SFace). Otherwise the most confident YOLO detection is cropped and its class becomes the search category.
> - **Object/appearance matching:** each candidate box in a sampled frame is compared with the reference using 55 % MobileNetV2 feature similarity + 45 % HSV colour-histogram correlation. A frame matches only if the score reaches the precision threshold (Strict 72 %, Balanced 65 %, Tolerant 55 %) and the colour correlation is at least 50 %.
> - **Reference videos:** up to 5 evenly spaced frames are used as references; a candidate matches if it matches any of them.
> - Matches less than 2 seconds apart are merged.
> Dimensions, timestamps or file names are never used to decide a match.
> 
> _Source: Smart Vision guide – How Fast Video Review finds matching frames_

### 31. What is the difference between precision and recall?

> - **Precision** = correct detections ÷ all detections made. High precision means few false alarms.
> - **Recall** = correct detections ÷ all objects that should have been found. High recall means few missed objects.
> - **F1-score** is the harmonic mean of precision and recall.
> - **mAP** (mean average precision) averages precision over recall levels and classes, using box overlap (IoU); it requires a labelled validation run.
> In Smart Vision's Research Evaluation, precision/recall are class-level: a scenario's detected labels are compared with its expected labels.
> 
> _Source: Smart Vision guide – Precision, recall, F1 and mAP explained_

### 35. What is the training dataset?

### 43. Why is detection failing on my phone?

> - If the panel shows **Model failed to load**, tap **Retry**. The error text explains the cause.
> - "No objects detected" means nothing scored above the **Confidence Threshold**. Improve lighting, move closer, or lower the threshold in Detection Settings.
> - The phone uses YOLOv8n at 320×320 pixels: small or distant objects can be missed and similar objects can be confused (for example knife vs scissors). The backend uses the larger YOLOv8m model, which is more accurate.
> - Detection only knows the 80 COCO classes listed in AutoML & Dataset Pipeline.
> 
> _Source: Smart Vision guide – Detection failing or inaccurate on the phone_

### 45. Why is the backend disconnected?

> The coloured **Server** light in the app bar shows the real server status (green online, red offline, grey not configured). Tap it for details. To connect:
> 1. On the computer run `uvicorn ai_server:app --host 0.0.0.0 --port 8000`.
> 2. Find the computer's Wi-Fi IP address (for example 192.168.1.20).
> 3. In the app open **Settings → Backend Server**, enter `http://192.168.1.20:8000` and tap **Save & test**.
> Do not use `localhost` on a phone – it means the phone itself. The Android emulator uses `http://10.0.2.2:8000`. Phone and computer must be on the same network and the firewall must allow port 8000.
> 
> _Source: Smart Vision guide – Backend connection_

### 49. How do I troubleshoot a failed video upload?

> - Check that the backend is **online** (green API light in the app bar).
> - Supported videos: mp4, mov, avi, mkv, webm, m4v, 3gp. Images: jpg, png, bmp, webp.
> - The server limit is 1 GB per file by default (`SMARTVISION_MAX_UPLOAD_MB`).
> - "could not be opened" means the file is corrupt or uses an unsupported codec – re-export it as H.264 mp4.
> - Large videos take longer: use 1 frame per second, keep the phone awake, and stay on the same Wi-Fi network.
> - "The server is already processing videos" means two searches are running; wait and retry.
> 
> _Source: Smart Vision guide – Video upload failed_

### 59. How do I change detection settings?

> Open **Detection Settings** on the Dashboard, Object Detection or Settings page:
> - **Confidence Threshold** (5–95 %): hides predictions below this score.
> - **IoU Threshold** (0.10–0.90): overlap used to remove duplicate boxes (non-maximum suppression).
> - **Maximum Detections** (1–300).
> Changes are saved on the phone and are used by live, image and video detection. The current image is re-analysed when you change a value. **Reset to defaults** restores 25 % · 0.45 · 100.
> 
> _Source: Smart Vision guide – Detection settings_
